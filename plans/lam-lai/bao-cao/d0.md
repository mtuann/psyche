## Commit và push: bạn chạy trên máy

Phiên Cowork không có quyền vào repo GitHub `mtuann/psyche` (repo chưa gắn với phiên, không có thông tin đăng nhập), máy ảo không chạy được git trong thư mục của bạn (không xóa được file khóa), và công cụ từ xa không được ghi vào `.github/`. Vì vậy ba file CI nằm trong `psyche-github.zip`, Claude đặt cạnh thư mục (`~/Desktop/work/projects/psyche-github.zip`; bản giống hệt cũng gửi trong cuộc trò chuyện).

1. Trên GitHub: repo `mtuann/psyche` → Settings → Pages → Build and deployment → Source: **GitHub Actions**. Repo riêng tư với GitHub Pro vẫn đăng được; trang Pages thì công khai.
2. Trong Terminal:

```bash
cd ~/Desktop/work/projects/psyche
unzip -o ../psyche-github.zip && rm ../psyche-github.zip    # 3 file CI vào .github/
git init -b main

# Đợt 0: kế hoạch và sổ tay, thẳng lên main
git add .gitignore AGENTS.md CLAUDE.md README.md plans ':!plans/lam-lai/bao-cao/d1-1.md'
git commit -m "Đợt 0: repo mới psyche, kế hoạch làm lại theo đợt, kế hoạch bền vững, lời giao việc" \
  -m "Co-Authored-By: Claude Opus 5.5 <noreply@anthropic.com>
Claude-Session: https://claude.ai/code/session_01MYyt7ZYqG5pKhK6uth75Sv"

# D1.1 trên nhánh riêng
git switch -c moi/d1-1-khoi-tao
git add -A
git commit -m "D1.1: khởi tạo Astro 7.4 và Starlight 0.42, font và màu của site cũ, trang chủ tạm, tìm kiếm không dấu, kiểm thử, CI song song" \
  -m "Co-Authored-By: Claude Opus 5.5 <noreply@anthropic.com>
Claude-Session: https://claude.ai/code/session_01MYyt7ZYqG5pKhK6uth75Sv"

git remote add origin https://github.com/mtuann/psyche.git
git push -u origin main moi/d1-1-khoi-tao    # test.yml chạy 6 job song song trên nhánh
```

3. Khi `test.yml` của nhánh xanh (tab Actions, khoảng 4 phút; lần đầu lâu hơn vì chưa có bộ đệm):

```bash
git switch main && git merge --ff-only moi/d1-1-khoi-tao && git push
```

`deploy.yml` chạy lại kiểm thử trên bản thật rồi đăng: https://mtuann.github.io/psyche/. `git status` sau bước 2 phải sạch; còn file lạ thì đừng push, báo lại.
