## Kiểm thử như trên GitHub

Clone nhánh vào thư mục tạm không có `../psyche-zero/` cạnh nó (như máy của GitHub), dùng `node_modules` chép từ repo:

| Phần | Kết quả |
|---|---|
| `npm run build`, `npm test` | 64 đạt, 3 bỏ qua (2 phép cần site cũ, 1 phép phạm vi: nhánh không phải nhánh lô) |
| `npm run build:xem`, `npm test` | như trên |

Kiểm thử trình duyệt ba trình duyệt và Lighthouse chạy ở D1.8 (có ba trang thử).
